# 🎮 PadLab — Universal Controller Studio

A browser-based controller lab for **PlayStation 4 (DualShock 4)**, **PlayStation 5 (DualSense)**, and **Xbox** controllers.

Built with plain **HTML, CSS, and JavaScript** — no build step, no backend. Ready to deploy on **GitHub Pages**.

![WebHID](https://img.shields.io/badge/WebHID-Chrome%2FEdge-green)

---

## ✨ Features

| Feature | PS4 | PS5 DualSense | Xbox |
|---|---|---|---|
| Real-time button & stick visualisation | ✅ | ✅ | ✅ |
| Visual skin colour changer | ✅ | ✅ | ✅ |
| **Real Lightbar colour (WebHID)** | ✅ | ✅ | ❌ (no RGB) |
| Analog **drift test** (3 s sample) | ✅ | ✅ | ✅ |
| Bilingual UI — **English (default)** + Arabic | ✅ | ✅ | ✅ |

- **5-second loading screen** with a progress bar and a **Continue** button.
- **Automatic controller detection** (PS4 / PS5 / Xbox) and the matching SVG layout is rendered.
- **Controller shapes** are simplified, original SVG illustrations inspired by open-source controller asset packs.
- **No data leaves your browser** — everything runs locally.
